Install in 4 steps

  1. On the main computer, run ShubhamDC-Server-Setup.exe → Next → Install (internet needed; 10-15 minutes).
  2. Open Shubham D&C from the desktop, enter your email + a password → First-time setup, then create your company.
  3. Press Alt+N (License) → fill your details → email OTP → your 45-day free trial starts.
  4. Staff computers: install the Windows App and enter the server address shown in the Setup Report.

After the trial, buy a license key and enter it on the same License screen. Your data is never deleted - without a license you can still view, print, export and back up everything.
